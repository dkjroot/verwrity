# Verwrity user guides

Here you'll find guides for writing, reviewing and looking after your projects in Verwrity.

Start with the first-days guide, then look up the tools you want to use. The feature reference goes into more detail.

- [Your first days with Verwrity](START-HERE.md): how to start a project, write a scene, keep notes and save your work. Includes screenshots and advice for coming back tomorrow.
- [Dictation, OCR and speed reading](IMPORT-AND-READING.md): record or import spoken drafts, bring in written pages, review the results and try the speed reader.
- [Dialogue and scene operations](DIALOGUE_AND_SCENES.md)
- [Feature reference](REFERENCE.md): detailed settings, optional AI and speech setup, limits and recovery.
